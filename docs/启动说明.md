# 拼词小院 · 启动说明

拼词塔防 M0 垂直切片 + M1 词表与拼写增强 + M2 战斗与配平 + M3 语音加成 + M4 素材与打磨：React 18 + Vite 6 + TypeScript 5.7，规则层为纯函数，内容由 JSON 驱动。跟读加成使用浏览器语音识别，需要 Chrome / Edge 桌面版或 Android Chrome，并通过 https 或本机地址打开。M4 加入 12 个原创角色的三档 PNG 美术、Kenney CC0 音效、自托管字体、图鉴与复习页、可调冻结时长与产物体积预算。

## 1. 环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 20（验证于 v24.22.1） | 开发、构建、测试均需要 |
| npm | ≥ 10 | 随 Node.js 安装 |
| 浏览器 | Chrome / Edge / Firefox 最新版 | 填词主玩法均可；跟读加成仅 Chrome / Edge 桌面版与 Android Chrome，需 https 或 localhost |
| 麦克风 | 可选 | 只有点「跟读加成」时才请求权限；拒绝后按钮置灰并说明原因 |
| Python + Pillow | Python 3.12 / Pillow ≥ 10 | 仅重新生成角色图（`scripts/matting.py`）时需要 |
| ffmpeg | 近期版本 | 仅把音效源文件重新转成 MP3 时需要 |

```bash
node -v
npm -v
```

## 2. 获取代码

```bash
git clone https://gitee.com/zwj_code/pvz-words.git
cd pvz-words
```

已在项目目录内可跳过本步。

## 3. 安装依赖

```bash
npm install
```

需要与锁文件完全一致时用 `npm ci`。

## 4. 启动开发服务器

```bash
npm run dev
```

- 默认地址：http://localhost:5173/
- 5173 被占用时 Vite 自动顺延端口，以终端输出为准
- 支持热更新，修改 `src/` 后页面自动刷新

## 5. 构建与预览

```bash
npm run build         # tsc --noEmit 类型检查 + vite build，产物在 dist/
npm run preview       # 本地预览构建产物，默认 http://localhost:4173/
npm run check:budget  # 产物体积预算：dist 总计 ≤ 3 MB，最大 JS ≤ 500 KB
```

## 6. 测试与质量检查

```bash
npm test                 # vitest run：28 个文件 / 187 个用例
npm run test:watch       # 监听模式
npm run validate:content # 独立内容门禁：植物/词表/配对/僵尸/关卡校验 + 36 张角色图校验，错误时退出码 1
npm run validate         # 内容门禁 + 20 个内容校验用例
npm run check:budget     # 构建产物体积预算（需先 npm run build）
npm run lint             # ESLint，含 src/rules 规则层纯度护栏
```

提交前建议完整跑一遍：

```bash
npm run lint && npm test && npm run build && npm run validate && npm run check:budget
```

## 8. 30 秒上手

1. 关卡选择页进入第 1 关。
2. 底部手牌 5 张，只有最左侧一张可以拼写；本关共 8 株植物（3 株中性苗木 + 5 株主题植物）。
3. 点击手牌打开拼词面板，按顺序点击字母块；拼错时该字母块按设置冻结 2 秒（默认，可在设置里改为 0 或 1 秒）。
4. 拼错 2 次会强调音标并朗读；拼错 4 次会高亮下一个正确字母，并记为「已用提示」。
5. 想给植物加攻击：在拼词面板点「跟读加成」并读出单词。读对后卡面显示「加成已备」，种下后 10 秒内该植物攻击 ×1.25，植物脚下有金色光环。
6. 读错记一次错词并可立即重试；没听清或识别服务出错不记错词。全局同时只保留一个语音加成。
7. 拼对后进入待种植状态，点击草坪格子种下植物，消耗阳光。
8. 阳光苗每 12 秒产出 25 阳光，三叶草每 12 秒产出 50，攒够阳光再多布防。
9. 普通 / 路障 / 铁桶 / 旗帜四类僵尸从右侧成波出现并向左推进，越过草坪最左侧即失败；撑过最后一波并清空即通关。
10. 右上角「退出」可随时离开本关，成绩不计入错词；选关页右下角「设置」里有 TTS 开关与语音隐私说明。
11. 选关页底部的「图鉴」可翻植物 / 僵尸 / 单词三页签，单词卡支持朗读；「复习」是只读错词统计，首局前显示空态。
12. 「设置」里除了 TTS 与语音隐私，还有音效开关和错字母冻结时长（0 / 1 / 2 秒），修改即时生效并写入存档。
13. 网址后加 `?perf=1` 可显示帧率面板（FPS / p95 / 场上数量），普通模式不显示。

## 9. 常见问题

- **端口被占用**：Vite 会自动换端口；也可 `npm run dev -- --port 5180` 指定。
- **启动后白屏并提示内容校验错误**：`src/content/*.json` 未通过 D21 校验，页面会拦住启动并显示原因；修复后可先跑 `npm run validate`。
- **切到后台标签页后游戏时间不走**：浏览器在隐藏标签页暂停 `requestAnimationFrame`，属预期行为，保持页面可见即可。
- **「跟读加成」按钮是灰的**：按钮不会隐藏，脚注会说明原因——非 https/本机地址会提示用 https 打开；Firefox 与 iPad Safari 不支持语音识别；拒绝过麦克风权限时按提示从地址栏重新开启。
- **跟读的隐私边界**：本游戏没有自己的服务器，也不保存录音。点跟读时浏览器会把音频发往它自己的语音识别服务（Chrome 走 Google）。填词主玩法不需要联网。
- **`npm run validate` 报角色图缺失/尺寸错误**：资产门禁会检查 12 个角色 × 3 档共 36 张 PNG 是否存在、尺寸是否为 96/128/256、是否带 RGBA。缺图时按提示重跑 `python scripts/matting.py --src art-source/plants --out public/assets/plants --sheet art-source/plants-sheet.png`（僵尸把 `plants` 换成 `zombies`），需要 Python 3.12 + Pillow。
- **点了按钮却没有音效**：浏览器只允许在用户手势后播放音频，先点一下页面再试；确认设置里「音效」为开启；iPad Safari 需关闭静音键。
- **重新生成角色素材 / 音效**：角色图用上面的 `scripts/matting.py` 命令重出三档；音效源文件转 MP3 需要 ffmpeg，来源与许可见 `public/assets/CREDITS.md`。
- **`npm run dev` 报 Node 版本过低**：升级到 Node 20 及以上。
- **Git 提示 LF 将被替换为 CRLF**：Windows 下 `core.autocrlf` 的正常提示，可忽略。
