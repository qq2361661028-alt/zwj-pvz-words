# 拼词小院 · 启动说明

拼词塔防 M0 垂直切片 + M1 词表与拼写增强 + M2 战斗与配平：React 18 + Vite 6 + TypeScript 5.7，规则层为纯函数，内容由 JSON 驱动。

## 1. 环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 20（验证于 v24.22.1） | 开发、构建、测试均需要 |
| npm | ≥ 10 | 随 Node.js 安装 |
| 浏览器 | Chrome / Edge / Firefox 最新版 | 需支持 CSS `transform` 与 `requestAnimationFrame` |

```bash
node -v
npm -v
```

## 2. 获取代码

```bash
git clone https://gitee.com/zwj_code/pvz-words.git
cd pvz-words
```

已在项目目录内可跳过本步。

## 3. 安装依赖

```bash
npm install
```

需要与锁文件完全一致时用 `npm ci`。

## 4. 启动开发服务器

```bash
npm run dev
```

- 默认地址：http://localhost:5173/
- 5173 被占用时 Vite 自动顺延端口，以终端输出为准
- 支持热更新，修改 `src/` 后页面自动刷新

## 5. 构建与预览

```bash
npm run build     # tsc --noEmit 类型检查 + vite build，产物在 dist/
npm run preview   # 本地预览构建产物，默认 http://localhost:4173/
```

## 6. 测试与质量检查

```bash
npm test                 # vitest run：20 个文件 / 128 个用例
npm run test:watch       # 监听模式
npm run validate:content # 独立内容门禁：植物/词表/配对/僵尸/关卡校验，错误时退出码 1
npm run validate         # 内容门禁 + 18 个内容校验用例
npm run lint             # ESLint，含 src/rules 规则层纯度护栏
```

提交前建议完整跑一遍：

```bash
npm run lint && npm test && npm run build
```

## 8. 30 秒上手

1. 关卡选择页进入第 1 关。
2. 底部手牌 5 张，只有最左侧一张可以拼写；本关共 8 株植物（3 株中性苗木 + 5 株主题植物）。
3. 点击手牌打开拼词面板，按顺序点击字母块；拼错时该字母块禁用 2 秒。
4. 拼错 2 次会强调音标并朗读；拼错 4 次会高亮下一个正确字母，并记为「已用提示」。
5. 拼对后进入待种植状态，点击草坪格子种下植物，消耗阳光。
6. 阳光苗每 12 秒产出 25 阳光，三叶草每 12 秒产出 50，攒够阳光再多布防。
7. 普通 / 路障 / 铁桶 / 旗帜四类僵尸从右侧成波出现并向左推进，越过草坪最左侧即失败；撑过最后一波并清空即通关。
8. 右上角「退出」可随时离开本关，成绩不计入错词。

## 9. 常见问题

- **端口被占用**：Vite 会自动换端口；也可 `npm run dev -- --port 5180` 指定。
- **启动后白屏并提示内容校验错误**：`src/content/*.json` 未通过 D21 校验，页面会拦住启动并显示原因；修复后可先跑 `npm run validate`。
- **切到后台标签页后游戏时间不走**：浏览器在隐藏标签页暂停 `requestAnimationFrame`，属预期行为，保持页面可见即可。
- **`npm run dev` 报 Node 版本过低**：升级到 Node 20 及以上。
- **Git 提示 LF 将被替换为 CRLF**：Windows 下 `core.autocrlf` 的正常提示，可忽略。
