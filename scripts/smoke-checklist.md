# 拼词小院 人工冒烟清单（M0 基线 + M1 增量 + M2 战斗配平）

环境：Chrome 或 Edge 桌面版，`npm run dev` → `http://127.0.0.1:5173`，浏览器窗口 ≥ 1280×720（画幅固定 1280×720，CSS transform 等比缩放）。M0 基线无语音；M1 新增音标强调、TTS 朗读与提示阶梯；M2 扩到 8 株植物、四类僵尸与按植物覆盖的产光量。§11-5 的「识别质量五种环境」不在本清单内；本清单只验手感与「不阻断」。

## 自动化门禁（先跑，全绿才做人工冒烟）

- [ ] `npm run lint` 无 error
- [ ] `npm test` 全绿

- [ ] `npm run validate` 全绿（D21 内容校验）

## A. 链路完整性（必须全过）

- [ ] A1 打开即是选关页「拼词小院」，点「Unit 3 · 第 1 关」进草坪
- [ ] A2 首张卡是 `sunflower 向日葵`（9 槽），右侧抽屉自动展开；点右侧任意一张卡 → 提示「只能先拼最左边的那张卡」
- [ ] A3 按顺序点对字母：每点一个，槽位多显示一个字母
- [ ] A4 点错一个块：面板抖动 + 提示「这个字母不对，换一个试试」，该块显示 2 秒倒计时且点不动；**已填字母没倒退、卡没消失**
- [ ] A5 填完出现「拼好啦！点草坪种下去」，手牌第一张变 armed；点「收起 ▾」后面板收起，僵尸恢复全速（对照收起前后的位移速度）
- [ ] A6 点草坪空格种植：阳光从 75 减到 35（阳光苗 cost 40）；格子出现阳光苗 SVG 轮廓
- [ ] A7 焦点是弹丸藤（cost 75）且阳光不足时点草坪 → 提示「阳光不够，等等苗木产光」，不扣阳光、不种植
- [ ] A8 种下阳光苗约 12 秒后看到阳光 +25（HUD 浮动 `+25`）
- [ ] A9 僵尸走到植物前停下啃食，植物血条出现并递减；植物被啃掉后僵尸继续前进
- [ ] A10 射手只打同 lane 且位于它右侧（x 更靠近房子）的僵尸；僵尸血条归零后消失
- [ ] A11 展开填词面板时僵尸明显更慢但仍前进（×0.85，D17 不是暂停）
- [ ] A12 撑到最后一波并清空 → 结算「通关啦！」；完全不填词放到最后 → 结算「小院失守」
- [ ] A13 点 HUD「退出」→ 结算「先歇一会儿 / 已退出本关，成绩不计入错词」，且话术里没有「失败」字样
